# Lumen & Oak — Interior Architecture Studio (Demo)

Fictional boutique interior studio landing page. Built as portfolio work to show premium, classic, minimalist design.

- **Stack:** Next.js 14 (App Router), Tailwind CSS, GSAP + ScrollTrigger
- **Style:** Ivory / ink / bronze, Cormorant Garamond + Inter
- **Sections:** Hero with line-mask reveal, stats counters, services marquee, selected works, philosophy, 3-step process, testimonial, contact + footer
- **Images:** Unsplash (free under Unsplash License), credited on-page
- **Data:** All projects, clients, stats are imaginary

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy on Vercel

Import this repo in Vercel, framework preset Next.js, no extra config needed.
